# KokiStyle — AI Agent Instructions

## Project Overview

KokiStyle is a premium remodeling and construction platform focused on the Florida USA market.

The platform showcases:
- remodeling projects
- before/after transformations
- virtual tours
- estimate generation
- premium luxury UI

Tech stack:
- Next.js 15
- TypeScript
- TailwindCSS
- Framer Motion
- pnpm
- Vercel

---

# Commands

## Install dependencies

```bash
pnpm install
```

## Run development server

```bash
pnpm dev
```

## Build production

```bash
pnpm build
```

---

# Architecture Rules

- Use reusable components
- Mobile-first responsive design
- Keep components small
- Use TypeScript interfaces
- Avoid duplicated code
- Use TailwindCSS only
- Maintain luxury premium aesthetic
- Prefer modular architecture

---

# Folder Structure

- components/layout → layout components
- components/ui → reusable UI
- components/sections → landing sections
- components/tours → virtual tours
- components/estimate → estimate system
- config → branding and constants

# Safety Rules

Ask before:
- installing large dependencies
- deleting files
- modifying config files
- changing deployment settings

Never:
- expose secrets
- hardcode sensitive data
- rewrite entire architecture unnecessarily
