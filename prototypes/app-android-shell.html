APP ANDROID (APK) — OPCIONES Y PROTOTIPO

Tres formas de tener tu APK. Las tres sincronizan solas con la app web (misma base de datos Supabase). Abajo, el prototipo de cómo se sentiría la app ligera.

RECOMENDADA

A · TWA (Bubblewrap) — tu PWA empaquetada como APK real

Un APK instalable (sideload o Play Store) que envuelve tu app web actual. Cero código duplicado: cada mejora de la web llega sola al APK. Ícono, splash, pantalla completa sin barra de navegador.

Esfuerzo: 1 día · Mantenimiento: casi cero · Costo: $0 (+$25 única vez si va a Play Store)
INTERMEDIA

B · Capacitor — webview + plugins nativos

Misma web dentro de un contenedor con acceso nativo extra (notificaciones locales, cámara nativa). Útil solo si algo web se queda corto.

Esfuerzo: 1-2 semanas · Mantenimiento: medio (dos builds) · Costo: $0
NO RECOMENDADA HOY

C · App nativa (Kotlin / React Native)

Máxima fluidez, pero duplicas TODO (pantallas, lógica, bugs ×2). Contradice tu objetivo de "fácil de implementar y mantener".

Esfuerzo: 2-3 meses · Mantenimiento: alto · Costo: alto
