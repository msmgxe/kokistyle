El ícono se instala con “Añadir a pantalla de inicio” desde un enlace con token de dispositivo. Al tocarlo, la app abre directo en el Dashboard — sin pedir PIN.

Shortcut sin login — ¿se puede para una persona y para el equipo?

Sí. Se hace con tokens de dispositivo: un enlace único y revocable por persona/aparato. Funciona igual para el admin solo o para todo el equipo, y cada quien conserva sus permisos (tab_access, my_tasks_only).

1
Generar enlace de dispositivo

En Ajustes → Seguridad, el admin crea un token por persona/aparato: kokistyle.vercel.app/acceso/tk_9f2…. Se guarda en la tabla device_tokens con expiración opcional.

2
Instalar en el teléfono

La persona abre el enlace en su celular o tableta y usa “Añadir a pantalla de inicio”. El PWA guarda la sesión — el ícono queda como una app normal.

3
Abrir directo, revocar cuando quieras

Cada apertura valida el token contra Supabase (server-side) y crea la sesión con los permisos de ese usuario. Si se pierde el aparato, el admin revoca ese token sin afectar a los demás.

Seguridad: el token nunca expone el PIN, es individual (no compartido), revocable uno por uno, y queda registrado en el Activity Log cada vez que se usa. Recomendado: expiración de 90 días renovable y máximo 2 dispositivos por persona.

Captura por voz o texto desde el celular

Reutiliza la infraestructura de Katy que ya existe en el proyecto (VoiceFAB + /api/voice + Claude). Se agrega la acción create_agenda_event: dictas o escribes la frase, Katy extrae tipo, fecha, hora, aviso y repetición, y muestra la tarjeta de confirmación editable — nada se guarda sin confirmar. Funciona igual con las 3 opciones de notificación.

1
Dicta o escribe

Desde el ícono de la pantalla de inicio (ya autenticado por el token de dispositivo), tocas el micrófono: “Reunión con la Sra. Herrera el martes a las 10, avísame cada 2 horas desde un día antes”. Web Speech API — el mismo motor del VoiceFAB actual, con modo teclado como respaldo.

2
Katy interpreta

El texto va a /api/voice (Claude) que devuelve la acción con los campos ya separados: tipo reunión · fecha martes · 10:00 · aviso desde 1 día antes · repetir cada 2 h. Con fallback local (localDetect) si no hay conexión al modelo.

3
Confirmas y se programa

La tarjeta de confirmación muestra todo editable. Al confirmar se inserta en agenda_events, los avisos quedan programados por el canal de la opción elegida, y la acción se audita en voice_actions.

Pruébalo arriba: la barra con el micrófono 🎙️ del panel es funcional — dicta (Chrome/Safari) o escribe la frase y toca Crear para ver cómo se llena la tarjeta de confirmación. En este prototipo el intérprete es local; en producción lo hace Claude vía /api/voice.
